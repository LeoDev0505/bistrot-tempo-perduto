# Bistrot del Tempo Perduto 

A modern, fully responsive web application developed for *Bistrot del Tempo Perduto*, a refined commercial venue located in Imperia, Italy. Designed in collaboration with artistic director Vanessa Crommar (*Paris Décor – Officina del Tempo Perduto*), the platform bridges aesthetic storytelling with high-performance frontend engineering.

## Key Features
* **Immersive Visual Design:** Tailored layout reflecting the sophisticated, vintage-modern atmosphere of the bistro.
* **Fully Responsive:** Optimized for seamless user experience across mobile devices, tablets, and desktops.
* **Interactive Sections:** Clean navigation showcasing the venue's identity, culinary offerings, and contacts.
* **Production-Ready:** High-speed asset loading and optimized performance.

## Tech Stack
* **Core:** React, TypeScript
* **Build Tool:** Vite
* **Styling & Architecture:** Component-driven modular design
* **Deployment & Hosting:** Netlify
